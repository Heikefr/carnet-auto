# Carnet auto

Application de suivi de voiture (pleins, entretien, coût réel au km), installable sur iPhone et utilisable hors connexion.

- Aucune donnée personnelle dans ce dépôt : les données restent sur le téléphone.
- Sauvegarde / restauration : onglet Véhicule > Sauvegarde (fichier .json).
- Export Excel / Google Sheets : onglet Véhicule > Pleins (.csv) / Entretiens (.csv).

Fichiers : index.html (l'application), car3d.js (modèle 3D de l'accueil), sw.js (hors connexion), manifest.webmanifest et icônes (installation sur l'écran d'accueil).
